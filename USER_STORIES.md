# User Stories - CodeCraftHub
1. As a new user, I want to sign up with my username, email, and password so that I can create a new account.
2. As a user, I want to receive validation error messages during signup if my credentials are invalid or missing.
3. As a registered user, I want to log into the application using my email and password to access my personalized dashboard.
4. As a user, I want to see an error notification if I enter incorrect login credentials.
5. As a user, I want to view a home screen with a branded logo and structured course listings.
6. As a user, I want to tap on a course to view its detailed information page.
7. As a user, I want my application preferences and course data to persist locally on my device using local storage.
8. As a user, I want the app to fetch dynamic course data from an external REST API.
9. As a user, I want to access settings and configure local push notifications to receive updates.
